# 🎨 Editor Gráfico – Java

Este projeto é um **Editor Gráfico** desenvolvido em **Java**, com foco no estudo de **Programação Orientada a Objetos**, **interfaces gráficas** e **manipulação de formas geométricas**.  
A aplicação permite ao usuário desenhar, visualizar e manipular elementos gráficos em uma interface desktop.

---

## 🎯 Objetivo do Projeto

Projeto desenvolvido com fins **acadêmicos e educacionais**, com os seguintes objetivos:

- Aplicar conceitos de **Programação Orientada a Objetos (POO)**
- Trabalhar com **interfaces gráficas em Java**
- Implementar um editor gráfico básico
- Manipular formas geométricas por meio de classes e herança
- Praticar organização e estruturação de projetos Java

---

## 🚀 Funcionalidades

- 🖌️ Criação de formas geométricas
- 📐 Manipulação de objetos gráficos
- 🧠 Uso de herança e polimorfismo
- 🪟 Interface gráfica para interação do usuário
- 🎯 Separação clara entre lógica e interface
- 🧩 Estrutura modular e extensível

---

## 🛠️ Tecnologias Utilizadas

- **Java**
- **Java Swing / AWT**
- **Programação Orientada a Objetos**
- **Interface Gráfica Desktop**
